# Contributing

Thanks for considering a contribution to these PostgreSQL notes!

## Guidelines

1. Keep one topic per file.
2. Use clear headings and include runnable SQL examples where possible.
3. Prefer PostgreSQL-version-agnostic notes; call out version-specific behavior explicitly.
4. Add references/links at the bottom of each note.
5. Run any SQL snippets locally before submitting.

## Submitting changes

1. Fork the repo and create a feature branch.
2. Make your changes following the folder structure in `README.md`.
3. Open a pull request using the provided PR template.
