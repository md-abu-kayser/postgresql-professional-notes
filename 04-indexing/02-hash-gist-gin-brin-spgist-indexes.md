# Other Index Types

- **HASH**: only equality.
- **GIN**: full‑text search, JSONB, arrays.
- **GIST**: geometry, full‑text.
- **BRIN**: block range indexes for very large tables.
- **SP‑GIST**: partitioned search trees.
