# PostgreSQL Professional Notes

A comprehensive, structured knowledge base covering PostgreSQL from fundamentals
to advanced production topics: data types, indexing, query optimization,
transactions, security, administration, high availability, scaling, extensions,
cloud/managed services, testing, migrations, and real-world project walkthroughs.

## Structure

- `00-prerequisites/` — relational DB concepts, installation, tooling
- `01-fundamentals/` — core SQL basics in PostgreSQL
- `02-data-types-deep-dive/` — types, JSON/JSONB, arrays, full text search
- `03-advanced-sql-features/` — CTEs, window functions, views
- `04-indexing/` — index types and strategies
- `05-query-optimization/` — EXPLAIN, execution plans, tuning
- `06-transactions-and-concurrency/` — ACID, MVCC, locking, vacuum
- `07-stored-procedures-and-functions/` — PL/pgSQL
- `08-security/` — roles, privileges, RLS, encryption
- `09-administration/` — configuration, backups, monitoring
- `10-high-availability-and-replication/` — WAL, replication, Patroni
- `11-scaling/` — read replicas, partitioning, sharding
- `12-extensions-and-ecosystem/` — PostGIS, pgvector, pg_cron, FDWs
- `13-cloud-and-managed-services/` — RDS, Cloud SQL, Azure, Neon, Supabase
- `14-testing/` — pgTAP, CI integration, pgbench
- `15-migration-from-other-databases/` — MySQL, SQL Server, Oracle
- `16-real-world-projects/` — end-to-end project case studies
- `17-code-snippets/` — reusable SQL snippets
- `18-resources-cheatsheets/` — cheat sheets, interview prep, further reading
